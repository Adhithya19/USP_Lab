Multi-file build and run steps:

Q4/2
  Build: gcc echoall.c -o echoall
  Build: chmod +x interp
  Build: gcc main.c -o main
  Run: .\main
  Notes: interp is a script with shebang #!./echoall, so echoall must exist in the same folder and interp must be executable.

Q8/2
  Build: gcc access.c -o access
  Build: gcc main.c -o main
  Run: .\main
  Notes: main.c executes ./access file.txt, so access must be built first.

Q11/2
  Build: gcc add.c -o add
  Build: gcc main.c -o main
  Run: .\main
  Notes: main.c executes ./add with sample arguments.

Q12/2
  Build: gcc echoall.c -o echoall
  Build: gcc main.c -o main
  Run: .\main
  Notes: main.c uses execle and execl to launch echoall.
